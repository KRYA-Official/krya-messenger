# 🌟 KRYA Official Shopping Mall

**KRYA** एक आधुनिक और सुरक्षित डिजिटल शॉपिंग प्लेटफ़ॉर्म है। हमारा लक्ष्य ग्राहकों को बेहतरीन उत्पाद और आसान भुगतान अनुभव प्रदान करना है।

## 🚀 मुख्य विशेषताएं (Features)
* **आधुनिक इंटरफेस:** यूजर-फ्रेंडली और तेज़ लोडिंग।
* **सुरक्षित लॉगिन:** OTP आधारित ईमेल वेरिफिकेशन।
* **आसान भुगतान:** सीधा UPI (PhonePe, GPay, Paytm) के माध्यम से पेमेंट।
* **एडमिन कंट्रोल:** एडमिन पैनल से सीधे प्रोडक्ट्स और यूजर्स को मैनेज करने की सुविधा।

## 🛠 तकनीक (Tech Stack)
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** Firebase Firestore
* **Auth:** EmailJS (OTP System)

## 📋 हमारा मिशन
ईमानदारी और पारदर्शिता के साथ डिजिटल उद्यमिता (Entrepreneurship) के क्षेत्र में सफलता प्राप्त करना।
